# PoE Act Timer

Оверлей для Path of Exile 1, который считает чистое игровое время прохождения сюжета (акты 1–10) и сам разбивает его по актам.

## Что считается

Время идёт, только когда персонаж реально играет. Таймер сам встаёт на паузу:

- игра свёрнута или окно не активно;
- выбор персонажа и главное меню;
- нет ввода с клавиатуры и мыши 20 секунд (эти 20 секунд тоже вычитаются);
- загрузочные экраны (их сумма показывается отдельно);
- зашёл другой персонаж;
- ручная пауза.

Забег начинается сам, когда новый персонаж появляется на Береговой полосе Сумерек, и заканчивается при входе на Берега Каруи после Китавы.

Если таймер был выключен, пока вы играли, при следующем запуске он догонит пропущенное по `Client.txt`. Время AFK за этот отрезок вычесть нельзя.

Язык плашки (русский или английский) выбирается по языку клиента игры.

## Безопасно ли это

Таймер не трогает игру: не читает и не меняет её память и файлы, не нажимает клавиши. Он использует только системные данные Windows (какое окно активно, когда был последний ввод) и читает лог `logs/Client.txt`, который игра сама пишет для сторонних программ.

## Установка

1. Скачайте `PoeActTimer.exe` со страницы Releases.
2. Положите в любую папку и запустите. Игра должна быть в оконном или полноэкранном оконном режиме.

Настройки (`config.json`), текущий забег (`state.json`) и история (`history.json`) хранятся рядом с exe. Если что-то пошло не так, ошибка записывается в `error.log` рядом с exe. Там же лежит файл лицензии шрифта `OFL-JetBrainsMono.txt`.

Путь к `Client.txt` определяется по запущенной игре; если не получилось, укажите его вручную через меню в трее.

## Управление

| Действие | Как |
|---|---|
| Пауза / продолжить | кнопка на плашке, `Ctrl+Alt+P` или меню в трее |
| Подробнее / кратко | ссылка на плашке или `Ctrl+Alt+E` |
| Сбросить забег | `Ctrl+Alt+R` или меню в трее |
| Начать забег с текущего места | меню в трее |
| История забегов | меню в трее |
| Указать `Client.txt` | меню в трее |
| Переместить плашку | тянуть за любое место, кроме кнопки и ссылки |

Меню в трее: «Пауза / Продолжить», «Начать забег с текущего места», «Сбросить забег…», «История забегов», «Указать Client.txt…», «Выход».

## Настройки

Все параметры лежат в `config.json` рядом с exe. Менять их нужно при закрытом таймере.

| Поле | Что делает |
|---|---|
| `LogPath` | путь к `Client.txt` |
| `AfkSeconds` | порог AFK в секундах, минимум 5 (по умолчанию 20) |
| `HotkeyPause`, `HotkeyToggle`, `HotkeyReset` | сочетания клавиш: пауза, подробнее / кратко, сброс |
| `OverlayX`, `OverlayY` | положение плашки на экране |
| `Opacity` | прозрачность плашки, от 0.2 до 1.0 |
| `Language` | язык плашки |
| `Expanded` | развёрнута ли плашка |

## Сборка

Нужен .NET 10 SDK.

    dotnet test
    dotnet publish src/PoeActTimer -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
